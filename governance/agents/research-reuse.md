# Research and reuse

Consult current internal Golden/approved donors before adding a new component,
provider or dependency. If the existing code solves the problem safely, do not
replace it for aesthetic consistency. Check license, provenance, security,
maintenance, runtime overhead and size before adopting OSS. Use external code
only when license-compatible; otherwise reuse concepts with independent code.
Never promote a donor to CERTIFIED because a single integration succeeded.
