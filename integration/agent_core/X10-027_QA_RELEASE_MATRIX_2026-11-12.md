## Gaps to close, ordered by dependency (no new engine duplication)

1. **P0 — X10-028, app-specific QA router and adoption.** Create a small adapter from per-product requirements to **existing** AppLab gate keys. Ensure required check truth/unknown states remain fail-closed; preserve FAST, FULL and CERTIFICATION authority and non-applicable hardware declarations. Run negative fixtures for unsupported/missing gates.
2. **P0 — X10-029, baseline coverage and visual regression.** Verify approved reference screenshots for each product's critical screens and supported modes (dark, localization, text scale, tablet as relevant). If no baseline exists, return NO_BASELINE/BLOCKED; don't create fake reference images or soften comparator thresholds to pass.
3. **P0 — X10-030, measurements + accessibility.** Need repeatable cold start, scroll responsiveness, layout/accessibility and device-specific evidence. Source exposes a Performance gate; this audit does **not** prove a particular app passed the measurements.
4. **P0 — X10-031, signed provenance pipeline.** Pin consumer source SHA, build policy, package/version, signer certificate SHA-256, APK/AAB hashes, target ABI and exact artifact link. Never claim runtime equivalence for ARM64-only APK tested only in x86_64 emulator.
5. **HUMAN_GATE — X10-032, real hardware and Play Internal Testing.** Operator session, real artifact SHA, install/update, FGS/OEM/background/billing consent/policy scenarios. Physical Evidence Hub verifies attested record/provenance, not unexecuted device operations or all referenced media bytes.
6. **P1 — X10-033, final decision aggregate.** Consume existing Release Reality + certification + device/distribution receipts. BLOCKED/NOT_VERIFIED remains visible. No new certificate authority and no Store publish without separate authorization.
